# DayTrace

Личный дневник атмосферы дня: превращает рассказ, фотографии и музыку в живую открытку 4:5 и сохраняет её в отдельную папку дня. В архиве заранее подготовлено 9 вымышленных записей, включая контрольную пару двух грустных дней с разной атмосферой («Дождливый вечер после экзамена» и «Последний вечер в старой квартире») и контрастный напряжённый день («Ночь в офисе перед сдачей»).

## Запуск

Нужен Node.js 22 или новее. Откройте терминал в папке `genesis-main`.

```powershell
npm start
```

Откройте [DayTrace](http://127.0.0.1:4173). Та же команда работает из корня проекта. По умолчанию записи лежат в корневой папке `vault/`. В папке дня находятся `entry.txt`, `memory.json`, автономная открытка `memory.html` и оригиналы медиа. При наличии озвучки Windows добавляется `voiceover.wav`. Любой день можно скачать одним ZIP-архивом.

Откройте день и нажмите «Сравнить музыку» над открыткой. Два встроенных WAV-этюда доступны без сети. Переключение сохраняет выбранное фото и позицию в пределах фрагмента. Кнопка «Сохранить этот трек» обновляет папку дня и ZIP. По общей ссылке посетитель видит сохранённую версию.

### Анализ новых записей

Сразу после запуска работают локальные правила. Они находят дословную цитату и название из 3–7 слов, оценивают структуру текста, палитру и свет снимков. Ключи, модели и Интернет для записи со своим аудиофайлом не нужны.

На Windows x64 с Python 3.11 или новее можно дополнительно установить локальную мультимодальную модель:

```powershell
python ../scripts/local_ai_setup.py
```

Установщик загружает около 1,6 ГБ и проверяет контрольные суммы файлов ([Qwen3-VL-2B-Instruct](https://huggingface.co/Qwen/Qwen3-VL-2B-Instruct-GGUF) · [llama.cpp](https://github.com/ggml-org/llama.cpp)). Для облачного анализа в корне проекта скопируйте `.env.example` в `.env`, укажите `GEMINI_API_KEY` и перезапустите сервер. При временной недоступности провайдера DayTrace использует локальные правила.

### Импорт из Google Фото

В форме «Новый день» доступны перетаскивание, выбор файлов, «Из папки» (рекурсивный поиск в распакованном альбоме) и прямой импорт «Из Google Фото» через Google Photos Picker API (при настроенном `GOOGLE_PHOTOS_CLIENT_ID`).

## Параметрическая визуальная система

Вместо жёстких шаблонов «грустно = синий» оформление каждого дня непрерывно вычисляется в `public/visual-recipe.js` на пересечении трёх модальностей:

- **Фотографии и видео** задают честную родную палитру (K-Means, до 5 цветов), световой профиль (`luma`, `contrast`, `warmth`), динамику движения (`videoMotion`) и автоматическую точку фокуса по цветовым границам и контрасту (`public/composition.js`, с ручной правкой кнопкой «Фокус»). Система не красит кадр чужим фильтром и не оставляет белую рамку — паспарту, рамки и родная палитра трансформируются в HSL под общий цветокор.
- **Текст** управляет композицией и типографикой: локальный анализ учитывает отрицания и противопоставления (`не`, `нет`, `но`, `зато`), выбирает конкретный заголовок из 3–7 слов и дословную цитату; длина фраз и пунктуация задают резкость склеек и вес шрифта; социальный масштаб — поля «воздуха» (`4.5%–45%`, принцип *Ма*).
- **Музыка** управляет физикой кадра по 4 независимым каналам (многооконный DSP-анализ аудиофайла в браузере с проверкой середины и концовки для длинных треков, каталог Spotify, Deezer API или ручной ввод / «Настучать ритм»): `BPM` задаёт интервал смены фото и скорость дрейфа, `major/minor` — поля и приглушённость, спектральная яркость — размер мазка и живое зерно плёнки, ударность (`positive spectral flux`) — конструктивистскую геометрию и реакцию на бит.
- **Конфликт модальностей**: яркий снимок + уставший текст не затемняют кадр и не запускают ливень — система сохраняет реальный свет, добавляя тёплую дымку, приглушение цветов, широкие поля и замедленный дрейф.
- **Художественные приёмы и референсы**: живописная мягкость и направленные мазки (*импрессионизм / Клод Моне*), широкие бумажные поля (*японский минимализм / Ма*), структурные оси, диагонали и бит-реактивная геометрия (*конструктивизм / Василий Кандинский*), живое зерно и тёплый ореол (*аналоговая киноплёнка*). Активные приёмы и точная трассировка каждой связи видны в панели **«Почему день выглядит так?» (X-Ray)** и в автономной открытке `memory.html`.
- **Лента архива** рендерит все карточки в едином формате 4:5 с индивидуальными полями, цветом бумаги, тонированной палитрой и ползунком «Ход времени» (выцветание открыток за год с плавным набором цвета при открытии дня).
- **Голос**: полный текст записи озвучивается с темпом и тембром, вычисленными по параметрам дня (на Windows сохраняется `voiceover.wav` с атмосферной фильтрацией в браузере; на других платформах используется `speechSynthesis`).

## Музыка и ссылки

При выборе «Автоподбор» дневник подбирает трек из подборки Spotify (16 треков с реальными профилями BPM, лада, яркости и ударности) либо через Spotify Web API при заданных `SPOTIFY_CLIENT_ID` и `SPOTIFY_CLIENT_SECRET`. Свой трек можно приложить аудиофайлом (браузер измеряет BPM, энергию, спектральный центр, ударность и мажор/минор по первым 30 с) или ссылкой с необязательными параметрами темпа, лада и характера звучания.

## Проверка

```powershell
npm test
```

Тесты проверяют параметрический движок и контрольную пару дней, DSP-анализ аудио и цветов, каталог Spotify, сохранение в `vault/`, досев новых версий демо-дней, ZIP-архивы, исполнение автономной `memory.html` и изоляцию ссылок.

## Использованные инструменты и ресурсы

- **Стек**: Node.js 22 (стандартная библиотека без сторонних npm-зависимостей), нативные ES-модули, WebGL (GLSL), Canvas 2D, Web Audio API, MediaRecorder, Web Speech API / Windows SAPI.
- **Опциональный AI**: Google Gemini API или локальная Qwen3-VL-2B-Instruct через `llama.cpp`.
- **Шрифты**: Manrope и Lora (SIL Open Font License, тексты лицензий в `public/fonts/`).
- **Демо-материалы**: фотографии природы и города с Unsplash ([перевал](https://images.unsplash.com/photo-1470071459604-3b5ec3a7fe05), [лес](https://images.unsplash.com/photo-1441974231531-c6227db76b6e), [ночной город](https://images.unsplash.com/photo-1519608487953-e999c86e7455), [море](https://images.unsplash.com/photo-1475924156734-496f6cac6ec1), [кофе](https://images.unsplash.com/photo-1442512595331-e89e73853f31), [домик у воды](https://images.unsplash.com/photo-1470770841072-f978cf4d019e), [горная долина](https://images.unsplash.com/photo-1464822759023-fed622ff2c3b)); сгенерированные демо-сцены `exam*.jpg`, `apartment*.jpg`, `office*.jpg` и синтезированные свободные от авторских прав аудио-этюды `after-exam.wav`, `last-apartment.wav`, `office-night.wav`.
