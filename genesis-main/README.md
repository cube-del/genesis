# DayTrace — Ящик с пластинками

> **ArtTech · Make the Invisible Visible**  
> Личный визуально-музыкальный дневник, который превращает реальные фотографии, видео, текст и музыку дня в живой **архивный контактный лист 4:5**, **разворот винилового конверта (Gatefold)** и **топографическую карту памяти**.

**DayTrace не генерирует фейковые изображения вместо фотографий пользователя.** Вся эстетика — цветокор, паспарту, типографика, композиция, погодный шейдер, ритм дыхания кадра и звуковой автограф — **непрерывно вычисляется из реальных данных дня** (текст + фото/видео + аудио).

---

## Быстрый запуск

Требуется **Node.js 22** или новее (внешние npm-зависимости не требуются):

```powershell
npm start
```

Откройте **http://127.0.0.1:4173**. При первом запуске в `../vault/` автоматически создаются 9 демонстрационных дней (включая контрольную пару двух грустных дней с разной атмосферой и контрастный напряжённый день).

Проверка всех 49 автотестов:

```powershell
npm test
```

## Основные фичи

1. **«Ящик с пластинками» и Топографический роадмап (`public/roadmap.js`):**
   * Карточки-конверты 4:5 с выезжающим винилом, калибровочной шкалой `■ ■ ■ ■` из 4 реальных цветов дня и зигзагообразным ритмом.
   * Гладкие волнистые контуры роадмапа на **центрипетальных сплайнах Катмулла–Рома ($\alpha = 0.5$)** с аналитическими нормалями и интерактивными флажками переходов.
2. **Journey Mode — «Проиграть маршрут» (`public/app.js`):**
   * Анимированная игла-маячок едет по роадмапу от карточки к карточке, плавно скролля страницу, запуская музыку и отображая сводку переходов (`BPM` и смена атмосферы).
3. **«Слепок архива» — генеративный виниловый постер LP (`public/vinyl-poster.js`):**
   * Музейный постер `1400×1750` (4:5), где каждое концентрическое кольцо — один день (цвет из K-Means палитры, рельеф бороздки из 56-точечной волны трека, BPM, энергии и `videoMotion`). Две темы печати (*«Тёмный винил»* и *«Бумажный оттиск»*), интерактивная подсветка дней и скачивание PNG.
4. **Разворот конверта (Gatefold), дыхание в бит и «Рентген-слой» (`public/day.js`):**
   * Живой WebGL GLSL-шейдер 60 FPS + плавное дыхание зума, света (`halation`) и рамки в точный такт BPM.
   * **«Рентген»** (кнопка под карточкой, удержание `Space` или клавиша `X`) — живой инженерный чертёж поверх сцены: прицелы `CV FOCUS`, палитра K-Means, телеметрия рецепта и 3-полосный FFT-спектр (`BASS / MID / HIGH`).
   * **«Кредиты»** (вклад в процентах: текст, фото/видео, погода, аудио), **Лупа** («Оригинал / Арт-слой»), **A/B-сравнение музыки**, озвучка дня, экспорт PNG / WebM 15 с / автономного **ZIP** с `memory.html`, шаринг по отзываемой ссылке и **удаление записей** (`DELETE /api/days/:id`).
5. **Физика времени («На полке — Сейчас»):**
   * Визуальная виниловая потёртость (`ring-wear`) и выцветание + **аудио-старение** в `Web Audio API` (low-pass фильтр и деликатный треск винила).
6. **Поддержка фото и видео + Google Фото Picker:**
   * До 5 медиафайлов в дне: фото до 50 МБ, видео MP4/WebM/MOV/OGG до 250 МБ, потоковая отдача `HTTP Range 206`, 4 опорных кадра и `videoMotion`.

## Инженерная начинка

* **Компьютерное зрение (`public/analysis.js`, `public/composition.js`):** K-Means (5 цветов), интегральное изображение `findFocus`, расширенный световой профиль (`luma`, `contrast`, `warmth`, `chroma`, `darkShare`, `brightShare`, круговой `dominantHue` `0–360°`) и `videoMotion`.
* **Кросс-модальный анализ (`server/atmosphere.mjs`, `server/rule-atmosphere.mjs`):** мультимодальный анализ **Google Gemini** (текст + фото + 4 кадра видео с таймкодами) и автономный отказоустойчивый NLP+CV движок с областью отрицаний (`не / без / не было`), усилением контраста (`но / зато`) и слиянием `fuseMood`.
* **Браузерный Audio DSP (`public/analysis.js`, `public/spectral-profile.js`, `public/media.js`):** автокорреляция BPM + Deezer API + Tap Tempo, определение мажора/минора (хромаграмма Гёрцеля + профили Крумхансла–Шмуклера), спектральный центроид (Гц), ударность (`percussiveness`), 56-точечная огибающая и живой 512-FFT.
* **4 параметрических стиля контактного листа (`public/visual-recipe.js`, `public/postcard.js`):** Импрессионизм (Моне), Конструктивизм (Кандинский), Японский минимализм (Ма), Киноплёнка 35mm.
* **10 живых атмосферных сценариев (`public/weather.js`, `public/day.js`):** `warm_haze`, `mist`, `rain_glass`, `wind_sparks`, `clear_light`, `snow_drift` (Снег и тишина), `starlight` (Звёздная ночь), `amber_bokeh` (Огни и боке), `petal_drift` (Листья и ветер), `neon_pulse` (Огни мегаполиса).

Подробная документация, схема архитектуры, карта всех модулей и описание HTTP API находятся в корневом [README.md](../README.md).
